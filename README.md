# CheckStock — Система оперативного учёта складских остатков (ФФ, FBS и FBO)

Веб-прототип на **FastAPI + SQLAlchemy (Async SQLite) + Jinja2** для сквозного учёта остатков товаров на физических складах фулфилмента (`Север`, `Юг`) и каналах продаж маркетплейсов (`Wildberries`, `Ozon`, `Яндекс.Маркет`).

## Ключевые возможности и архитектура

* **Сквозной расчёт остатков (ФФ / FBS / FBO):**
  * **Физические склады (`Север`, `Юг`):** хранят физический остаток (`physical_qty`) и автоматически вычисляют доступный к продаже остаток (`Доступные = Наличие − Резерв FBS`) с привязкой каждого резерва к складу-источнику (`source_ff_id`).
  * **Маркетплейсы (`WB`, `Ozon`, `Яндекс.Маркет`):** раздельный учёт активных резервов **FBS** (`reserved_qty`) и партий в пути **FBO** (`transit_qty`).
* **Управление движениями товаров:**
  * **Приход и возвраты (`/stock/income`):** оприходование от поставщика (включая автоматическое создание новых артикулов `SKU` на лету), возврат из резерва FBS, возврат из транзита FBO обратно на полку ФФ и внутренние перемещения между складами.
  * **Отгрузка и резервирование (`/stock/transfer`):** резервирование под заказы FBS, отгрузка в транзит FBO и межуровневые перемещения с защитой от отрицательных остатков.
* **Асинхронный транзакционный стек:** полностью неблокирующий бэкенд на `FastAPI` + `SQLAlchemy AsyncSession` (`sqlite+aiosqlite:///:memory:`), готовый к переходу на **PostgreSQL** заменой строки подключения `DATABASE_URL`.
* **Защита данных и интерфейс:** валидация количества (`quantity > 0`), нормализация артикулов, безопасное экранирование уведомлений и таблица с фиксированной шапкой (`position: sticky`).

## Стек технологий

* **Backend:** Python 3.12+, FastAPI, SQLAlchemy 2.0 (Async), Jinja2
* **База данных:** SQLite (`aiosqlite`, in-memory)
* **Тестирование:** Pytest (`pytest-asyncio`)

## Локальный запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите сервер (на свободном порту `5050` во избежание конфликтов с зарезервированными портами Windows):
   ```bash
   python app/main.py
   ```
   *(Либо через Uvicorn: `python -m uvicorn app.main:app --host 127.0.0.1 --port 5050`)*

3. Откройте в браузере:
   `http://127.0.0.1:5050`

## Запуск автотестов

```bash
python -m pytest -v
```
